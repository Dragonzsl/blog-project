# 产品范围

一次部署只有一个站点和一个站主，主要用于个人写作与公开阅读。

## 已实现

- 文章和页面，Markdown 编辑、预览、快照、修订、定时发布、撤回和回收站。
- 版本对比与恢复预览、批量内容操作、排期日历。
- 分类、标签、导航、媒体、引用保护和重定向。
- 公开页面缓存、中英文搜索、SEO、RSS、Sitemap 和 robots。
- 密码/TOTP、恢复码、会话撤销和 CLI 认证恢复。
- 备份、校验、隔离恢复、恢复演练和升级前恢复点。
- WordPress、Ghost、Markdown 导入和内容归档。
- 主题包安装、设置、预览、切换、回退与移除后重新添加。
- 默认关闭的评论、统计、Newsletter、内容 API 和 Webhook；可配置 S3 与 SMTP 适配器。

操作说明见[使用手册](usage.md)。已有代码和测试不等于所有部署环境都已通过验收；资源指标仍需在目标服务器实测。

## 范围外

多租户、多站点、协作者/RBAC、读者账户、付费会员、支付、自定义内容类型、多语言内容关联、页面搭建器、公开写 API、GraphQL、任意服务端脚本和在线插件市场。

主题可以上传模板和静态资源；插件必须是编译进程序的可信 Go 代码。生产不依赖 Redis、消息队列或独立搜索服务。
