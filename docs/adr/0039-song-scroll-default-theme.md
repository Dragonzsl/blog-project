# 默认主题采用宋韵山水意境

## 决策

内嵌默认主题采用宋韵纸墨与柔和圆角，取代 ADR-0029 的视觉方向。公开页面使用暖纸色、松绿和少量朱砂强调；本地宋体与楷体作为字体首选并安全回退。桌面导航横向呈现，窄屏使用第二行可横向滚动的导航。首页以文字主视觉、推荐文章与最近文章构成阅读入口；文章、集合、目录、搜索和状态页面共享同一视觉令牌。

页面底层使用一幅原创横幅水墨山水，以绢纸色遮罩压低对比度。图像嵌入默认主题，通过内容指纹 URL 提供并使用一年不可变缓存；不添加独立装饰插画。无第三方资源请求。

## 保持的约束

- 页面仍由受限的 Go `html/template` 服务端渲染，内容仅来自安全公开视图模型。
- 保留浅色、深色与跟随系统模式；深色配色切换为墨石色纸面和淡朱色强调。
- 保留键盘焦点、跳过导航、无 JavaScript 阅读路径、减少动态效果、文章目录、主题切换和插件插槽。
- CSS、JavaScript、首屏和页面响应继续遵守 ADR-0031 的既有预算。

## 原因

站点希望默认主题更接近宋代山水的层峦、烟岚和留白。内嵌轻量本地画作与绢纸遮罩能建立这一氛围，同时不把背景细节放在文字阅读的视觉层级之上，也不引入外网依赖。

## 后续视觉迭代（2026-09-26）

后续实现保留宋韵纸墨、全页低对比水墨背景和本地字体回退，将表面、按钮与信息卡片改为柔和圆角。首页改用文字主视觉，不再绘制独立立轴插画；首页、文章列表、归档和文章详情分别使用独立路由。页眉以横向导航呈现，搜索入口打开 Spotlight 式对话框，`/search` 只作为无 JavaScript 的服务端搜索入口。控件和导航文案采用常见博客用语，文章题目和正文仍由作者决定。

## 默认主题复核（2026-10-03）

- 推荐区域使用单列标题与紧凑卡片，避免旧版双栏规则挤压标题；卡片和列表保持整块链接。
- 首页页眉常驻，其他页面自然滚动；自定义导航子项保持可访问。
- 搜索对话框限制在可视高度内，保留焦点指示、Esc 关闭与关闭后焦点恢复；取消旧搜索并拒绝过期响应。
- 旧主题包缺少分页辅助模板时，核心补充默认模板；保留已有自定义分页。
- HTML 的 ETag 条件优先于更新时间条件，避免主题更新后浏览器继续使用旧 HTML。
- 浏览器目录夹具通过 `THEME_ARTICLE_FIXTURE=/posts/<slug>` 指定，需已发布且包含二级标题。
