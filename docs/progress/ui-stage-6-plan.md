# 阶段六设计方案：自适应双侧栏与阅读体验

更新时间：2026-08-29

状态：已实施，验收通过

## 1. 目标

在阶段五全站侧栏基础上，进一步完成“内容优先”的双侧栏阅读体系：

- 全局站点导航位于左侧，支持展开、收缩和移动端抽屉。
- 文章目录位于右侧，支持展开、关闭和断点自适应。
- 主题默认跟随系统，并允许用户覆盖为亮色或暗色。
- 移动端文章降低无效字号和留白，提升长文阅读密度。
- 增加低存在感的回到顶部按钮，且不影响滚动位置和阅读连续性。
- 公共阅读端、文章预览、后台管理端使用一致的交互语义。

本阶段只调整界面层、视图模型和渐进增强脚本，不引入重型前端框架，不改变单站主、SQLite 和插件默认关闭的产品边界。

## 2. 设计方向

采用“左侧全局导航 + 中间正文 + 右侧文章目录”的内容优先结构：

```text
宽屏桌面
┌──────────────┬──────────────────────────────┬──────────────┐
│ 全局站点侧栏 │ 文章标题、正文和文章操作     │ 文章目录     │
│ 240–256px    │ 最大约 720–760px             │ 220–240px    │
│ 可收缩为72px │ 保持 65–75 字符阅读行长       │ sticky       │
└──────────────┴──────────────────────────────┴──────────────┘

窄屏设备
┌────────────────────────────────────────────┐
│ 顶栏：菜单、站点名、主题                    │
├────────────────────────────────────────────┤
│ 单列文章正文                               │
│ 目录按钮 → 右侧全高目录抽屉                │
└────────────────────────────────────────────┘
```

参考 [ChatGPT Learn Quickstart](https://learn.chatgpt.com/docs/quickstart) 的信息组织方式，借鉴分组导航、文档搜索、当前页面高亮和响应式侧栏；不复制其品牌标识、颜色或具体视觉资产，继续保持本站安静的编辑出版物风格。

## 3. 响应式断点契约

| 设备范围 | 全局站点导航 | 文章目录 | 正文布局 |
| --- | --- | --- | --- |
| `>= 1440px` | 左侧常驻，默认展开，可收缩为 72px | 右侧常驻、sticky，可关闭为窄触发条 | 正文 + 右侧目录三栏 |
| `1024–1439px` | 左侧抽屉，默认关闭 | 右侧抽屉，默认关闭 | 单列正文 |
| `768–1023px` | 左侧抽屉，默认关闭 | 右侧抽屉，默认关闭 | 单列正文，保留舒适边距 |
| `<= 767px` | 左侧全高抽屉 | 右侧全高抽屉 | 移动端单列长文阅读 |

断点仍以内容是否能保持可读行长为判断依据，不为了强行展示三栏而压缩正文。公共导航、文章目录和后台导航分别拥有独立的状态，不用页面类型推测当前状态。

## 4. 全局站点侧栏

### 4.1 视觉结构

```text
品牌标识                         收缩/关闭

站点
  首页
  文章
  归档

探索
  分类
  标签
  搜索

更多
  RSS
  关于

────────────────────────
主题：自动 · 暗色
查看后台 / 站主管理
```

- 分组标题使用小号辅助文字，不与导航项争夺视觉层级。
- 当前页面使用苔绿色指示线、浅色背景和字重变化共同表达，不只依赖颜色。
- 图标继续使用同源 SVG，装饰图标设置 `aria-hidden="true"`。
- 收缩状态保留图标轨道；每个图标仍有可访问名称和键盘焦点，不把 hover tooltip 当作唯一说明。

### 4.2 展开与关闭

- 宽屏默认展开，侧栏可以切换为 72px 图标轨道。
- 侧栏宽度变化只由用户主动触发，不在滚动过程中自动改变。
- 宽屏侧栏固定在视口左侧，导航列表独立滚动；收缩状态保留固定的展开按钮，避免用户失去导航入口。
- 平板和移动端默认关闭，使用左上角菜单按钮打开左侧抽屉。
- 平板和移动端菜单按钮脱离顶栏流式布局，页面下滑后仍固定显示；侧栏打开时仍可用内部关闭按钮收起。
- 抽屉支持关闭按钮、遮罩点击和 `Escape` 关闭。
- 打开时锁定背景滚动，关闭后恢复触发按钮焦点。
- 公共端站点侧栏与文章目录互斥；打开一个时自动关闭另一个。

建议使用以下本地状态：

| 状态 | 建议值 |
| --- | --- |
| 站点侧栏 | `expanded` / `collapsed` / `closed` |
| 后台侧栏 | `expanded` / `collapsed` / `closed` |
| 保存位置 | `localStorage`，按端区分键名 |

### 4.3 按钮位置与展示策略

- 两个入口都脱离页面标题和顶栏的流式布局，使用 `position: fixed` 固定在视口安全区内；站点导航按钮保持左上角，文章目录按钮保持右侧中线附近，页面下滑后仍可见。
- 宽屏（`>= 1440px`）保留左侧常驻导航和右侧常驻目录：左侧按钮位于导航轨道顶部，用于展开/收缩导航；右侧按钮紧邻目录外侧，用于展开/收起目录。目录收起后正文网格不产生空白栏。
- 平板和移动端使用同一按钮完成打开与关闭，不同时展示第二个重复关闭按钮：站点抽屉打开后左按钮移动到抽屉右边缘并切换为关闭图标；目录抽屉打开后右按钮移动到抽屉右上角并切换为关闭图标。
- 按钮触控区域分别保持不小于 `44px` 和 `48px`，使用安全区偏移、半透明表面和低对比度边框，避免遮挡标题、正文操作和回到顶部按钮。
- 两个抽屉互斥；打开一个抽屉时关闭另一个，按钮状态同步 `aria-expanded`、`aria-label` 和视觉图标，关闭后恢复原触发按钮焦点并保持正文滚动位置。

## 5. 文章目录改为右侧

### 5.1 宽屏

- 目录位于正文右侧，宽度约 220–240px。
- 使用 `position: sticky`，顶部偏移避开顶栏和阅读进度条。
- 目录最大高度使用视口高度减去安全边距，过长时只滚动目录区域。
- 目录头部提供明确的“收起目录”按钮。
- 宽屏默认常驻展开，正文上下滑动时目录保持在右侧；目录过长时只滚动目录自身，标题栏保持可见。
- 宽屏和窄屏始终保留右侧悬浮目录把手，使用简洁双横线图标；宽屏把手负责收起/恢复目录，窄屏把手负责打开/关闭右侧抽屉。

### 5.2 平板和移动端

- 目录从右侧滑入全高抽屉，宽度为 `min(88vw, 340px)`。
- 右侧悬浮目录把手固定在视口中线附近，不依赖文章头部位置；窄屏页面下滑后仍可直接打开目录。
- 抽屉头部显示当前文章标题或“文章目录”，右上角提供关闭按钮。
- 点击章节后关闭抽屉，跳转到稳定标题锚点，并保持用户的阅读上下文。
- 目录打开时隐藏回到顶部按钮，避免右下角控制叠加。

### 5.3 目录状态与无障碍

- 服务端只输出一份目录 DOM，不为桌面和移动端复制两份内容。
- 目录标题使用稳定 ID，正文标题设置 `scroll-margin-top`。
- 当前章节使用 `aria-current="location"` 和可见的强调状态。
- 打开、关闭、遮罩和 `Escape` 均支持键盘操作。
- 没有 H2/H3 的文章不输出空目录栏、目录触发器或无效留白，正文恢复单列。
- 无 JavaScript 时，目录仍以普通的页面内链接呈现，不阻塞正文阅读。

## 6. 主题模式：自动优先

主题由三种状态组成：

```text
自动跟随系统
亮色模式
暗色模式
```

规则如下：

1. 首次访问默认使用“自动跟随系统”。
2. 通过 `matchMedia('(prefers-color-scheme: dark)')` 读取系统主题。
3. 系统主题发生变化时，只有“自动”状态跟随变化。
4. 用户手动选择亮色或暗色后保存本地覆盖状态。
5. 公共页面、文章预览、后台、登录和初始化页面共享同一主题偏好。
6. 首屏尽早读取偏好，避免刷新时出现亮暗主题闪烁。
7. 主题切换只改变颜色 token 和极短过渡，不刷新页面、不回到顶部、不丢失表单输入。

主题控件建议显示实际状态，例如：

```text
自动 · 暗色
自动 · 亮色
亮色模式
暗色模式
```

颜色继续使用语义 token。暗色模式采用降低饱和度的浅色文字和深色表面，正文、辅助文字、边框、代码块、焦点环和遮罩分别验证对比度，不能简单反转颜色。

## 7. 移动端文章阅读

### 7.1 字号和密度

- 正文保持 16–17px，不低于 16px。
- 正文行高约 1.75–1.85，保证中文连续阅读舒适度。
- 移动端文章标题控制在约 36–48px，避免标题占据多个屏幕。
- H2 约 24–28px，H3 约 20–22px。
- 日期、标签、阅读时间等辅助信息控制在 12–14px。
- 收敛标题区、段落区、卡片和页脚的垂直留白约 15–25%。
- 正文宽度维持约 65–75 个字符，不使用全屏宽度铺满长文。

### 7.2 内容适配

- 长 URL、文件名和标签使用 `overflow-wrap: anywhere`，不能撑破页面。
- 代码块保留横向滚动，复制工具栏固定在代码块顶部。
- 表格使用独立滚动容器，不能撑破正文布局。
- 图片、引用、列表和相邻文章卡片适配窄屏边距。
- 文章底部操作区预留安全空间，不被固定控件遮挡。
- 使用 `dvh`、安全区变量和适配的底部内边距，兼容移动端地址栏变化。

## 8. 回到顶部按钮

回到顶部按钮作为辅助能力，不作为页面主 CTA：

- 滚动超过约 400px 或一屏后出现。
- 位于右下角安全区域，移动端避开底部手势区。
- 视觉主体使用小箭头、细边框和半透明表面，触控区域不小于 44px。
- 可用一圈极细的阅读进度环表达当前进度，但不使用高饱和大面积按钮。
- 接近页面顶部时自动隐藏。
- 打开站点导航或文章目录时隐藏。
- 点击后平滑回到顶部；开启减少动画时使用即时定位。
- 仅使用轻量的 `IntersectionObserver` 或节流滚动检测，不在每一帧执行布局查询。
- 通过键盘触发后，将焦点合理返回主要内容区域，不制造焦点丢失。

## 9. 公共端和后台端页面范围

### 9.1 公共页面

统一调整以下页面的共享壳层：

- 首页
- 文章列表
- 文章详情
- 归档
- 分类
- 标签
- 搜索
- 404、500 和其他状态页
- 主题预览页

所有页面使用相同的全局侧栏、主题控件、跳过导航链接和焦点行为。文章详情额外使用右侧目录体系。

### 9.2 后台页面

后台侧栏沿用相同的展开/收缩/抽屉协议，分组保持：

```text
工作台
  总览

内容
  文章
  页面
  回收站

站点
  内容组织
  媒体库

外观与扩展
  主题
  插件
  重定向
```

- 编辑器收缩侧栏后，为正文编辑区释放空间。
- 后台编辑、文章预览和公共文章页共享主题偏好。
- 登录和初始化页面不显示工作台侧栏，只提供主题入口。
- 保存、发布、筛选、分页、恢复和删除操作不强制回到页面顶部，而是回到当前列表或目标行。

## 11. 性能和可访问性要求

- 不引入第三方字体 CDN、重型 UI 框架或大型动画库。
- 抽屉和按钮动效优先使用 `transform`、`opacity` 和已有 CSS token。
- 不对正文做视差、滚动劫持或持续动画。
- 页面首屏和无 JavaScript 版本必须可以阅读核心内容。
- 所有按钮和导航项触控区域至少 44px。
- 所有图标按钮具备明确的 `aria-label`、`aria-expanded` 或 `aria-pressed` 状态。
- 键盘顺序与视觉顺序一致，抽屉打开时焦点不穿透到背景。
- 支持 `prefers-reduced-motion`，减少动画时仍保持状态反馈。
- 375px 宽度不出现横向滚动；长文行长保持可读。
- 主题切换前后正文、辅助文字、边框和焦点状态都满足可读对比度。
- 滚动监听使用被动事件、节流或观察器，避免主线程持续布局计算。

## 12. 实施顺序

### 阶段 6A：设计 token 和状态协议

- 确认断点、侧栏宽度、正文宽度和移动端间距 token。
- 将主题偏好扩展为 `system/light/dark` 三态。
- 统一公共端、后台端和预览页的侧栏属性和焦点协议。

## 13. 验收标准

### 功能

- [ ] 公共端和后台端侧栏都可以主动展开、收缩和关闭。
- [ ] 宽屏文章目录位于右侧，窄屏目录从右侧打开。
- [ ] 站点导航和文章目录互斥，不会出现双遮罩或双滚动锁定。
- [ ] 主题默认跟随系统，手动选择可以持久化。
- [ ] 回到顶部按钮按滚动距离出现和隐藏。
- [ ] 无目录文章没有空目录栏和无效目录按钮。

### 阅读体验

- [ ] 375px 页面没有横向滚动。
- [ ] 移动端正文不低于 16px，标题和留白不再过度占屏。
- [ ] 目录定位不会把标题藏在顶栏下方。
- [ ] 搜索、筛选、主题切换、目录切换和回到顶部不产生异常回顶。
- [ ] 代码、表格、图片、长标题和长 URL 都能稳定渲染。

### 无障碍与性能

- [ ] 所有交互控件至少有 44px 触控区域。
- [ ] 键盘可以完成侧栏、目录、主题和回到顶部操作。
- [ ] 抽屉支持焦点管理、Escape 和遮罩关闭。
- [ ] 亮暗主题的正文、辅助文字、边框和焦点状态均可辨识。
- [ ] 减少动画设置下没有非必要动画。
- [ ] Lighthouse 的 CLS、INP、LCP 不因本阶段出现明显回退。

## 14. 本阶段不做

- 不增加读者账号、关注、点赞或社交关系。
- 不引入完整文档站生成器或复杂页面搭建器。
- 不使用大面积粒子、视差、自动轮播或滚动劫持。
- 不把主题偏好存入服务器数据库。
- 不为了展示目录而牺牲正文行长或移动端可读性。
