### 2. 唯一站主、密码/TOTP、会话、CSRF、CLI 恢复

- 首次设置采用 15 分钟服务端挑战，只能事务性创建一个站点和一个站主；数据库与应用共同保持唯一行约束。
- 密码使用带独立随机盐的 Argon2id（64 MiB、3 次、单并行），认证内存并发固定为 1，并在低频认证操作后主动归还内存页。
- TOTP 强制绑定，密钥由运行时认证秘密通过 AES-GCM 加密；未配置环境秘密时原子生成权限为 `0600` 的本地秘密文件。
- 生成 10 枚约 80 bit 的单次恢复码，只保存带服务端秘密的 HMAC；恢复码登录在创建会话的同一事务内消费。
- 会话只保存随机令牌摘要并绑定认证版本；Cookie 使用 `__Host-`、Secure、HttpOnly、SameSite=Strict，密码/TOTP 恢复会使所有旧会话失效。
- 初始化、登录和退出全部验证 CSRF 与 Origin；登录失败采用有界限速表，Argon2 并发为 1，未知用户名执行同参数假哈希。
- `blog auth recover` 从标准输入或权限受限文件读取新密码，轮换密码、TOTP、恢复码与认证版本，不依赖邮件或外部服务。
- 管理入口提供无 JavaScript的现代编辑式初始化、TOTP、恢复码、登录和概览页面，并设置严格 CSP、Permissions-Policy 与禁止缓存。
- 自动验证：普通测试、CLI 集成测试、HTTP 全流程、恢复码单次使用、跨站拒绝、race、`go vet`、依赖校验和 Compose 配置均通过。
- 运行与视觉验证：HTTPS 安全头和 Cookie 属性正确；1440×900 与 390×844 均无横向溢出；镜像约 13.8 MB；完成真实 Argon2 初始化后应用约 7.85 MiB，Caddy 约 16.08 MiB。

### 4. 默认主题、Markdown 清洗、缓存、渲染失效

- 使用 Goldmark 的 GFM、脚注、排版替换与自动标题 ID 渲染 Markdown；Bluemonday 显式允许列表在模板接收可信 HTML 前移除原始脚本、事件属性和危险 URL。
- 默认主题以嵌入式模板和指纹 CSS 交付，无公开阅读 JavaScript 或第三方请求；首页、文章页和私密预览共享现代编辑式视觉语言，并保持预览提示与返回编辑入口。
- 公开文章只渲染 `published_revision_id`，私密预览只渲染当前修订且设置 `no-store`；发布后的草稿不会进入公开 HTML 或缓存。
- 页面快照先原子写入磁盘，并放入最多 32 项、4 MiB 的有界 LRU 热点缓存；键包含主题版本、语义页面和数据库 `render_epoch`，发布后自动失效且最多分批清理 100 个陈旧文件。
- 页面响应提供内容 ETag、条件请求、HEAD、公开安全头和缓存命中标记；主题 CSS 使用内容指纹、年度缓存与 `immutable`。
- 公共修订时间独立于当前草稿更新时间，确保 `Last-Modified` 不会因未发布编辑而改变。
- 默认容器预算收紧为应用 256 MiB、Go 堆 192 MiB、Caddy 64 MiB；真实 Argon2 身份测试在 256 MiB 限制内通过。
- 自动验证：Markdown 清洗、主题转义、磁盘/内存缓存边界、ETag/304/HEAD、预览隔离、发布失效、全量测试、race、`go vet`、`go mod verify`、Compose 配置和差异检查全部通过。

### 5. 页面、分类、标签、导航、本地媒体

- Publishing 扩展为文章与页面共用的内容内核和独立后台入口；页面使用根路径 `/{slug}`，文章继续使用 `/posts/{slug}`，系统路径统一保留且 Unicode slug 进行 NFC 归一化和大小写键约束。
- 文章支持一个扁平分类与最多 30 个扁平标签，页面明确不使用分类标签；公开详情和分类/标签归档都只读取已发布修订中的公开 ID 快照，草稿组织调整不会提前泄漏。
- 导航作为 Organization 独立模块管理主导航与页脚导航，支持内容、分类、标签和安全 HTTP(S) 外链，并由数据库与服务共同限制为一层子项；默认主题在桌面、键盘焦点和移动布局中展示子导航。
- Media 模块采用稳定 128-bit 公开 ID 与不可变 URL；允许 JPEG、PNG、PDF、纯文本和 ZIP，默认拒绝 SVG，校验 MIME、像素与上传大小，并在正文引用不存在媒体时拒绝保存。
- 原始上传文件按原始字节保存且测试逐字节一致；图片预览串行生成，使用 Catmull–Rom 缩放、JPEG 默认质量 92、PNG 无损压缩，避免额外常驻图像服务，并在处理后主动归还内存页。
- 上传上限、像素上限、预览宽度和 JPEG 质量均可通过 TOML 或环境变量配置；默认值分别为 12 MiB、1600 万像素、640/1280 px 和质量 92。
- 媒体删除会同时检查当前草稿与线上已发布版本的引用；从草稿移除引用不会误删仍在线的文件，只有再次发布解除引用后才允许删除。
- 页面、内容组织和媒体后台沿用现代编辑式视觉体系；公开页面、分类/标签列表、导航和文章分类标签纳入默认主题及渲染缓存失效机制。

### 6. 版本、编辑快照、定时发布、撤回、回收站

- 版本列表只读取元数据，查看单个版本时才加载完整正文，避免长文章历史造成后台瞬时大内存；默认仅保留最近 50 个普通版本，发布检查点永久保留。
- 恢复历史版本会创建新的不可变修订，不覆盖历史记录；已经发布过的内容继续保持稳定永久链接，并恢复对应分类和标签快照。
- 编辑器每 15 秒仅在内容变更后提交一份可覆盖的服务端快照，不创建正式版本；快照使用浏览器版本与内容锁双重并发检查，正式保存后清除，跨发布状态变化可安全重基。
- 支持按站点时区定时、重新定时和取消定时；单一低频后台循环在启动时及默认每 15 秒领取到期内容，使用条件更新保证重复执行不重复发布，并为每篇内容独立处理失败。
- 支持撤回公开内容，撤回后公开地址立即返回 404，但保留历史版本和永久路径；再次发布可恢复原路径。
- 回收站支持内容移入、列表和恢复，恢复时统一回到草稿；默认 30 天后由同一生命周期工作器每 6 小时分批永久清理，已使用的永久路径仍保留，避免链接被其他内容接管。
- 调度间隔、批量大小、编辑快照间隔、普通版本上限、回收站保留天数和清理间隔都可配置；空闲时只维持一个工作协程和两个低频计时器。

### 7. SEO、RSS、Sitemap、重定向、全文搜索

- 新增 Discovery 模块，以 SQLite FTS5 保存有界搜索投影；英文支持 Unicode 分词与前缀匹配，中文使用最多 4096 个去重大字组辅助召回，查询结果只读取标题、摘要、路径和发布时间，不把正文载入结果集。
- 发布、撤回、回收站和分类标签修改通过数据库触发器登记待同步内容；应用启动、定时发布后和搜索前按默认 20 条的小批次同步，不新增搜索服务、外部队列或常驻工作器。
- 公开搜索支持文章/页面、分类、标签与相关度/发布时间筛选，限制 2–100 字符和最多 50 条结果；搜索页禁止缓存和索引，CSP 只允许搜索表单同源提交。
- 公开页面输出 canonical、Open Graph、Twitter summary、RSS discovery 和 WebSite/BlogPosting/WebPage/CollectionPage JSON-LD；JSON-LD 使用逐响应 SHA-256 CSP 哈希，不开放任意内联脚本。
- 内容编辑、不可变版本与编辑快照新增独立 SEO 标题和描述；公开页面优先使用覆盖值，留空时回退到内容标题、摘要与站点名。
