# 主题与插件契约

## 核心原则

主题负责呈现，插件负责能力。两者都有清单、版本、兼容范围、配置 schema 和启停状态，但安全模型不同：主题是站主上传的受限模板资源，插件是随官方发行物编译的可信 Go 代码。

## 主题包

主题以 ZIP 分发，解包后结构如下：

```text
theme.json
templates/
  base.html
  index.html
  article.html
  page.html
  collection.html
  search.html
  error.html
  partials/
assets/
locales/
  zh-CN.json
preview.webp
LICENSE
```

`theme.json` 建议字段：

```json
{
  "id": "org.example.paper",
  "name": "Paper",
  "version": "1.0.0",
  "themeApi": "1",
  "core": ">=1.0.0 <2.0.0",
  "features": ["dark-mode", "toc", "comments-slot"],
  "settingsSchema": {
    "accent": {"type": "color", "default": "#3157d5"},
    "contentWidth": {"type": "integer", "minimum": 640, "maximum": 840, "default": 760},
    "showReadingTime": {"type": "boolean", "default": true}
  }
}
```

设置类型第一版只允许 boolean、受限 integer、text、color、select、media 和 URL。Schema 不能声明代码、HTML 或任意文件路径。核心负责生成后台表单和默认值，主题只读取验证后的配置。

## 主题视图模型

主题只接收不可变、版本化的公开视图：

- `SiteView`: 名称、描述、主要语言、规范 URL、图标和社交链接。
- `ContentView`: 类型、标题、摘要、安全正文 HTML、永久链接、发布时间、封面、分类标签、阅读时间和 SEO。
- `CollectionView`: 条目、分页、集合名称和规范 URL。
- `NavigationView`: 已解析且经过安全检查的导航树。
- `MediaView`: 稳定 URL、宽高、替代文本和变体列表。
- `PageContext`: 当前模板、主题设置、可用功能和 CSP nonce/资源信息。

主题看不到内部数据库实体、草稿、邮箱、文件路径、插件配置或 SQL。新增可选字段保持向后兼容；删除或改变语义只在新的主题 API 主版本发生。

## 模板函数

白名单函数只做确定且有界的展示工作，例如 URL 构造、日期格式、翻译、分页、资源指纹、JSON 安全序列化和渲染固定插槽。模板函数不得发网络请求、读任意文件、执行命令、写数据库或访问环境变量。

正文以已经清洗的安全类型进入模板；只有核心可以构造该类型。主题传入普通字符串时仍由 `html/template` 自动转义，主题不能调用通用 `safeHTML` 绕过。

## 标准插槽

插件不能依赖主题 DOM 结构，只能向核心定义的插槽贡献内容：

- `head.metadata`
- `body.start`
- `article.before`
- `article.after`
- `article.comments`
- `body.end`

插槽输出由可信官方插件生成，并受 CSP 与资源清单约束。主题可以选择插槽位置，但声明支持某项能力后必须渲染对应必需插槽。未安装评论插件时，评论插槽为空。

## 主题安装与启用

安装流程是：流式接收 → 大小/文件数限制 → 临时目录解包 → 拒绝绝对路径、`..`、符号链接和特殊文件 → 校验清单 → 解析全部模板 → 使用固定样例渲染 → 检查必需模板、资源引用和 API 兼容 → 原子移动到主题目录。

启用前用真实站点数据在隔离预览路径渲染首页、文章、页面、集合、空状态和错误页。全部成功后在一个事务中切换活动主题并提高 `render_epoch`；失败保留旧主题。默认主题内嵌程序，永远是故障回退选项。

## 默认主题

默认主题实现 ADR-0029：现代编辑式极简、单栏、中文与英文混排友好、浅色/深色/跟随系统、无 JavaScript也可完整阅读。默认不请求外部字体、分析、图标或脚本；CSS 压缩后不超过 40 KiB，阅读必需 JavaScript 不超过 15 KiB。

配置只暴露能保持设计质量的少量参数：强调色、正文宽度、密度、圆角、代码主题、列表封面、阅读时间、目录、上一篇/下一篇和社交链接。它不是页面搭建器。

## 插件接口

每个官方插件提供静态清单和一个注册入口。概念接口如下：

```go
type Plugin interface {
    Manifest() Manifest
    Register(Host) error
}
```

`Host` 不是应用容器，只暴露按能力拆分的窄接口：

- 注册自身命名空间下的公开或后台路由。
- 注册设置 schema 与后台菜单项。
- 订阅版本化的提交后事件。
- 登记有版本、幂等键和有限重试的持久任务处理器；需要和业务写入原子完成时使用宿主提供的事务内入队能力。
- 注册内容指令、评论提供方或存储适配器等明确扩展点。
- 向标准主题插槽贡献受控输出和静态资源。
- 使用宿主日志、时钟、HTTP 客户端和秘密引用读取能力。

插件不能获取裸 `*sql.DB`、通用文件系统、进程执行器或任意模板集合。网络访问必须通过受限适配器，统一超时、禁止自动重定向、响应体上限和私网地址策略。

## 生命周期

插件代码在编译时登记，但默认不初始化。启用过程依次验证核心 API、配置、秘密引用和前置能力，再注册路由/任务并运行健康检查；任一步失败则保持禁用。

禁用时停止接收新请求、事件和新任务；已有 pending 任务保留在统一队列中，running 任务依靠短租约恢复，重新启用后再按策略消费。配置、任务、投递记录和数据均保留。删除数据是独立危险操作，必须列出表和对象、创建备份并再次确认。

第一版插件之间没有直接依赖关系，也不能调用另一插件的具体实现。需要协作时使用核心能力接口或版本化事件，避免形成不可安装的依赖图。

## 事件与任务

核心事件示例：`ContentPublished.v1`、`ContentUpdated.v1`、`ContentUnpublished.v1`、`ContentDeleted.v1`、`CommentApproved.v1`、`ThemeActivated.v1`。事件只包含公开 ID、版本和必要小字段，不携带完整正文或秘密。

事件由核心在业务事务内写入 `event_outbox`，并创建 `core:event_dispatch` 任务；提交后才调用启用插件的订阅者。同步事件处理器只能执行快速、本地、不会失败的登记工作；邮件、Webhook、远程 API 和重计算必须转为持久任务。每个任务类型包含载荷版本和幂等键，升级时必须仍能读取尚未执行的旧载荷版本。人工重试复用原任务行并写入审计，不能通过新建任务绕过幂等键。

评论和 Newsletter 的匿名写入由核心的 keyed 幂等/短期指纹边界保护。Newsletter 的确认邮件和外部同步均是持久任务；原始 token 不进入日志，token 链接所需的密文只用于受保护的站内异步发送流程。

## 官方插件目录

| 插件 | 默认 | 能力 |
|---|---|---|
| Local Comments | 关闭 | 匿名评论、审核、回复、垃圾处理、邮件通知适配 |
| External Comments | 关闭 | 选择一个外部评论提供方并占用评论插槽 |
| Local Analytics | 关闭 | 隐私型日/月聚合与可选阅读量 |
| Content API | 关闭 | `/api/v1` 只读已发布内容 REST/JSON |
| Webhooks | 关闭 | 签名事件投递、有限重试和失败记录 |
| S3 Storage | 关闭 | 媒体和备份对象存储适配器 |
| SMTP Mail | 关闭 | 站主通知与评论通知，不承担 Newsletter 会员系统 |
| External Newsletter | 关闭 | 订阅表单与外部邮件列表服务连接 |

SEO、RSS、Sitemap、重定向、搜索、备份和默认本地存储不是插件，因为它们属于核心发布或恢复职责。

## 内容指令

复杂 Markdown 内容使用版本化指令，例如图库、提示框、外部视频。指令由核心或可信插件注册，语法必须能在纯文本中识别并保留未知指令。渲染器遇到未安装指令时显示安全占位而不是丢弃源文本。

每个指令声明参数 schema、是否允许远程资源、渲染缓存影响和导出降级文本。指令不能成为任意 HTML/JavaScript 注入通道。

## 兼容与发布

主题 API 与插件 Host API 分别版本化。清单同时声明核心语义版本范围；升级预检用真实已安装扩展运行解析与渲染夹具。兼容测试通过不代表性能通过，主题仍需满足 ADR-0031 的页面预算。

第三方主题可以独立许可，但分发包必须包含许可证。第一版不建立在线市场、自动下载、签名信任根或动态服务端插件生态。
