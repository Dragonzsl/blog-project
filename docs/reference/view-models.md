# 主题视图模型参考

主题 API 当前为主版本 `1`。字段只增不删；改变字段语义必须提升主版本。主题永远看不到草稿、邮箱、内部数据库 ID、文件系统路径、插件秘密或 SQL。

| 模型 | 内容 |
|---|---|
| `SiteView` | 站点名称、描述、主要语言、规范 URL、社交链接 |
| `ContentView` | 类型、标题、摘要、安全正文 HTML、永久链接、发布时间、封面、分类、标签、阅读时间、SEO |
| `CollectionView` | 集合标题、条目、分页、规范 URL |
| `NavigationView` | 经过安全解析的导航树 |
| `MediaView` | 稳定 URL、尺寸、替代文本、派生版本 |
| `PageContext` | 当前模板、已验证主题设置、功能开关、资源信息 |

模板函数只做 URL、日期、翻译、分页、资源指纹和 JSON 安全序列化等确定性展示工作。任何网络、命令执行、任意文件访问或数据库写入都不属于主题能力。
